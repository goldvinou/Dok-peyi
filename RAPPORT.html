1 Présentation du projet

Dok'péyi est un site web de services administratifs en Guyane française. Les clients font une demande en ligne (CV, lettre, dossier, courrier) et l'administrateur génère les documents via IA (Claude Haiku) depuis un panneau admin.

4 Ce qui a été fait

A — Site client

  • Formulaire multi-étapes : choix service → coordonnées → détails → confirmation
  • 4 services : CV, Lettre de motivation, Dossier administratif, Courrier officiel
  • Formulaire CV avec 2 chemins : "Créer de A à Z" (champs texte) ou "Améliorer mon CV" (upload fichier + note)
  • Sélecteur d'indicatif téléphonique international (+594, +33…)
  • Système multilingue (FR/EN/ES/PT/HT)
  • Design moderne type Apple/Tesla

B — Panneau admin (5 sections)

  • Tableau de bord — KPIs, graphiques revenus (Chart.js)
  • Demandes — liste filtrée, recherche, statuts, modale de détail
  • Services & Tarifs — modifier prix et descriptions
  • Configuration IA — 5 prompts éditables par l'admin (NOUVELLE section)
  • Statistiques — graphiques par service et par mois
  • Génération document IA depuis la modale de chaque demande
  • Visualisation + téléchargement du document généré (aperçu HTML + impression PDF)
  • Envoi par email (mailto) et WhatsApp (wa.me)

C — API serverless (api/generate-cv.js)

  • Proxy Anthropic pur : reçoit { prompt }, renvoie { cv: html }
  • Le prompt est construit côté client (admin.js) avec des templates {{variable}}
  • Utilise https.request (Node.js natif, pas de fetch)
  • CommonJS (module.exports) — compatible Vercel sans "type":"module"

D — Système de prompts IA éditables

  • 5 templates configurables depuis l'admin : cv_scratch, cv_improve, lettre, dossier, courrier
  • Sauvegardés dans localStorage['dok_ai_prompts']
  • Variables disponibles dans les templates :

{{nom}} {{email}} {{tel}} {{poste}} {{experience}} {{formation}} {{competences}} {{infos}} {{note}} {{entreprise}} {{motivation}} {{type}} {{description}} {{documents}} {{destinataire}} {{objet}}

api/generate-cv.js (état actuel)

const https = require('https');

module.exports = async function handler(req, res) {
  res.setHeader('Access-Control-Allow-Origin', '*');
  res.setHeader('Access-Control-Allow-Methods', 'POST, OPTIONS');
  res.setHeader('Access-Control-Allow-Headers', 'Content-Type');
  if (req.method === 'OPTIONS') { res.status(200).end(); return; }
  if (req.method !== 'POST')   { res.status(405).json({ error: 'Method not allowed' }); return; }

  const apiKey = process.env.CLAUD_API_KEY;
  if (!apiKey) { res.status(500).json({ error: 'CLAUD_API_KEY non configuree' }); return; }

  const { prompt } = req.body || {};
  if (!prompt || typeof prompt !== 'string' || !prompt.trim()) {
    res.status(400).json({ error: 'Prompt manquant ou invalide' });
    return;
  }

  try {
    const bodyStr = JSON.stringify({
      model: 'claude-haiku-4-5-20251001',
      max_tokens: 4096,
      messages: [{ role: 'user', content: prompt }]
    });
    const result = await new Promise((resolve, reject) => {
      const options = {
        hostname: 'api.anthropic.com', path: '/v1/messages', method: 'POST',
        headers: {
          'x-api-key': apiKey, 'anthropic-version': '2023-06-01',
          'content-type': 'application/json',
          'content-length': Buffer.byteLength(bodyStr)
        }
      };
      const req2 = https.request(options, r => {
        let data = '';
        r.on('data', c => { data += c; });
        r.on('end', () => resolve({ status: r.statusCode, body: data }));
      });
      req2.on('error', reject);
      req2.write(bodyStr);
      req2.end();
    });

    if (result.status !== 200) {
      res.status(500).json({ error: 'Anthropic ' + result.status + ' : ' + result.body.substring(0, 400) });
      return;
    }
    const data = JSON.parse(result.body);
    const html = (data.content && data.content[0] && data.content[0].text) || '';
    res.status(200).json({ cv: html });
  } catch (err) {
    res.status(500).json({ error: 'Erreur : ' + err.message });
  }
};

Contexte technique important

  • Site 100% statique — pas de build step, pas de npm install nécessaire
  • La seule partie "serveur" est api/generate-cv.js (fonction Vercel serverless)
  • Le fichier api/generate-cv.js utilise CommonJS (module.exports) — ne pas le convertir en ESM
  • Le plan Vercel est Hobby → limites : timeout fonction 10s max, pas de custom domain avancé
  • La variable d'environnement s'appelle exactement CLAUD_API_KEY (pas CLAUDE_API_KEY)
  • Tout le localStorage est perdu si l'utilisateur vide son cache — c'est voulu (pas de DB)
